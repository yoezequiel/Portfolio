## Overview

**Forge** es un laboratorio para generar secretos de forma segura: contraseñas, frases de paso, API keys, claves SSH, hashes, identificadores, JWTs y secretos TOTP. Todo se ejecuta **del lado del cliente**: no se sube, registra ni almacena nada en un servidor.

Está pensado para desarrolladores y personas preocupadas por la seguridad que quieren una herramienta seria y moderna.

## Key Features

- **🔑 Credenciales**: Generador de contraseñas, frases Diceware, medidor de fortaleza (zxcvbn) y validador de políticas.
- **🗝️ Claves**: Generación de API keys, claves SSH (Ed25519 / RSA), ECDSA (P-256 / P-384) e intercambio X25519.
- **🎲 Aleatoriedad**: UUID v4 y v7, NanoID, ULID, CUID2 y bytes aleatorios.
- **🔐 Criptografía**: Hashes con WebAssembly, JWT con `jose` y secretos TOTP con código QR.
- **🛡️ Privacidad por Diseño**: Cero backend; todo usa la Web Crypto API y librerías auditadas como `@noble/curves`.

## Technical Challenges

Implementar operaciones criptográficas en el navegador exige usar fuentes de aleatoriedad seguras y librerías confiables, y presentar los resultados en formatos estándar (PEM, OpenSSH, Base32) que funcionen en herramientas reales.
